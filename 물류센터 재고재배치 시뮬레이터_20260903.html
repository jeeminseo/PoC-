📐 통로 전용 동선 산출 및 알고리즘 계산 근거

1. 통로 경유(Aisle-Only) 이동 경로

Path: Rack(X,Y) ➔ Facing_Aisle ➔ Main_Cross_Aisle ➔ Dock(0,0)
Dist = (X_Aisle_Dist + Y_Aisle_Dist) + (Z - 1) * 2.0m

  • 파렛트랙 관통 방지: 작업자가 파렛트랙을 가로지르지 않고 전면 통로로 빠져나온 후 통로 중심선으로 이동합니다.
  • 메인 통로(Cross Aisle) 우회: 통로를 통해 하단 메인 통로로 이동한 뒤 입출고구(Dock)로 직선 접근합니다.
  • Z축 단수 가중치: 1단 상단 작업 시 장비 상하차/수직 이동 시간을 수평거리 2.0m 추가 이동으로 반영합니다.

2. 슬롯팅 재배치 알고리즘

1. Total_Dist_Daily = Sum(Daily_Touch * Dist * 2)
2. SKU List ➔ Daily_Touch 내림차순 정렬
3. Rack List ➔ Dock 실제 통로 거리(Dist) 오름차순 정렬

  • 왕복 피킹 동선: 입출고구 출발 ➔ 통로 경유 피킹 ➔ 복귀하는 왕복 거리(x 2) 산출.
  • ABC 최적화 매핑: 통로 경유 동선 기준으로 Dock과 가장 가까운 통로 입구 및 1단 골든존에 고터치 SKU를 최선순위 할당합니다.

3. 인력 및 작업시간 절감 계산

Total_Hours = Total_Dist_Daily / (Speed * 60)
Saved_Hours = AS-IS_Hours - TO-BE_Hours
Man_Power_Saved = Saved_Hours / Work_Hours_Daily

  • 소요 시간: 이동거리(m)를 피커 평균 보행 속도(m/min)로 나누어 총 이동시간 산출.
  • 인당 부담시간: 일일 총 이동시간을 입력된 피커 인원수(Workers)로 분배.
  • 공수 절감 환산: 절감된 총 공수(Man-Hours)를 규정 근로시간으로 나누어 인력 감축 효과를 제시.
